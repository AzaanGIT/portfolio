## 🚀 Featured Repositories & Projects

### 🔬 VLSI & Physical Design
- **[Physical Design of SPI Controller using Qflow](https://github.com/AzaanGIT/portfolio)**  
  Complete RTL-to-GDSII ASIC implementation flow on the OSU018 (180 nm) standard cell library: logic synthesis (Yosys), floorplanning, placement, CTS, routing, STA (OpenSTA), and DRC/LVS physical sign-off.
- **[ML-Based Routing & Congestion Predictor for RV32I Processor](https://github.com/AzaanGIT/portfolio)**  
  Predicts routing congestion hotspots early from floorplan knobs and routing resources using Cadence sweeps (30,500+ samples) and recommends parameter adjustments before routing failure.
- **[Digital FSM Controller for Automated Washing Machine](https://github.com/AzaanGIT/washing-machine-fsm-verilog)**  
  Synchronous 7-state FSM controller designed in Verilog HDL with debounce filtering, 2-stage synchronizers, per-state watchdog timer, and GTKWave verification.

### 🤖 Embedded Systems & Robotics
- **[Multi-Degree-of-Freedom Robotic Arm Design & Kinematics Control](https://github.com/AzaanGIT/robotic-arm-kinematics)**  
  Articulated 3-DOF spatial robotic arm with analytical forward/inverse kinematics (IK/FK), non-blocking cubic trajectory interpolation, autonomous pick-and-place sequencer, and Python 3D workspace visualizer.
- **[Wireless Light-Intensity Controlled Motor using RF Communication](https://github.com/AzaanGIT/wireless-rf-light-motor-control)**  
  Closed-loop wireless cyber-physical control system transmitting 433 MHz RF telemetry from an optical LDR sensor to dynamically regulate a remote DC motor via an L298N driver with 3-bit binary LED telemetry.
- **[Directional Optical Visitor Counter & Automated Power Management](https://github.com/AzaanGIT/bidirectional-visitor-counter)**  
  Smart building occupancy monitor with dual-beam optical IR sequence detection, threshold alarms ($\ge 30$), automated zero-standby energy relay, and real-time IoT dashboard.
- **[Smart Rover: Multi-Function Robotic Car](https://github.com/AzaanGIT/portfolio)**  
  Arduino-based autonomous rover with ultrasonic obstacle avoidance, Bluetooth mobile telemetry, serial console control, and voice navigation.
- **[Intelligent IV Therapy Monitoring & Flow Control](https://github.com/AzaanGIT/portfolio)**  
  Real-time biomedical automation device tracking fluid depletion and wirelessly dispatching nurse alerts via ESP8266.

### 📊 Machine Learning & Communications
- **[Employee Pay Scale Estimator](https://github.com/AzaanGIT/Employee-Pay-Scale-Estimator)**  
  End-to-end Machine Learning salary tier classification system trained on the UCI Census dataset using Gradient Boosting (85.85% accuracy) deployed with an interactive Streamlit web application.
- **[Dispersion Compensation Techniques in Radio over Fiber (RoF)](https://github.com/AzaanGIT/rof-dispersion-compensation)**  
  Simulation suite evaluating DCF, FBG, and EDC across 10–80 Gbps data rates and 20–60 GHz mmWave RF carriers with eye diagrams and BER curves.
