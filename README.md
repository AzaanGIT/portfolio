# AZAAN'S PORTFOLIO

A personal portfolio website built with pure HTML, CSS, and JavaScript.

## Pages
- `index.html` — Hero / Home
- `about.html` — About me
- `projects.html` — Project showcase
- `skills.html` — Skills & RTL-to-GDS flow
- `experience.html` — Work & education timeline
- `gallery.html` — Photography gallery
- `contact.html` — Contact form
- `resume.html` — Resume viewer

## Stack
- Pure HTML5 / CSS3 / Vanilla JS (no frameworks)
- Fonts: Urbanist, Cormorant Garamond, JetBrains Mono (Google Fonts)
- Fully responsive, accessible

## Live
Deploy via GitHub Pages — go to **Settings → Pages → Branch: main → / (root)**
